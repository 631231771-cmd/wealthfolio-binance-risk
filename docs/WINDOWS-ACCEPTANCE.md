v0.1.3 已在 2026-10-14 完成独立资料升级、假凭据保存/真实重启读回/替换/用户删除及再次 null 读取。当前只有 secrets.set/get/delete 和文件保存权限，没有网络或宿主资产读写。本版不执行下面旧版宿主导入步骤；结果和边界以 VALIDATION 最新节为准。后续真凭据仍禁止，AI 当前访问勾选尚未隔离。

状态：**2026-10-13 官方客户端 v3.9.1 已完成 v0.1.1 数据路径验收及 v0.1.2 缺陷修复复验**。v0.1.2 已真实升级、检查失败/部分/零资产/无快照/缺价与失败状态重启。逐项实际结果见 [VALIDATION](VALIDATION.md)；宿主写入基线来自 v0.1.1，本次未重做完整宿主写入。网络、桌面导出恢复和控制台尚未验证。以下为复验步骤。

## 准备

1. 从 [官方 v3.9.1](https://github.com/wealthfolio/wealthfolio/releases/tag/v3.9.1) 下载适合电脑的 `Wealthfolio_3.9.1_x64-setup.exe`（ARM 电脑选 arm64），确认应用版本 3.9.1。
2. 新建独立测试资料库/个人资料，基准币种选择 USD。不要使用含真实资产的资料库。插件模拟资产会计入主程序测试总资产。
3. 在插件管理页选择本地 ZIP 安装：`artifacts/wealthfolio-binance-risk-0.1.2.zip`；审核账户创建、持仓读写、模拟报价、文件导出和 `api.binance.com` 网络权限。没有 secrets 权限，不应要求密钥。安装批准须由用户亲自操作；本次已批准且用户确认网络主机保持关闭。原 v0.1.1 权限页显示「已拒绝」，本轮未开启或检测网络。
4. 看到侧栏「币安风险 · 模拟」，打开页面。若权限/兼容/路由被拒绝，记录错误，**停止后续接入，不改主程序**。

## 检查与期望

| 操作 | 验收结果 |
|---|---|
| 点击读取主程序账户和持仓 | 返回数量，无上传；空测试资料库可为 0 |
| 点击模拟同步两次 | 只有 Spot/Funding 两个成功模拟快照；Stocks unsupported；小计 30000 USD；完整总资产不可用 |
| 检查风险结果 | Spot/Funding 24000/6000；最大账户权重 0.8；最大资产权重 0.833333；HHI 0.68/0.722222；压力损失 5500 |
| 点击导入模拟持仓并读回核对两次 | 两个 WRISK 账户，HOLDINGS 模式，各两条持仓；读回成功，没有重复账户或增仓 |
| 在主程序账户/持仓页核对 | WRISKDEMO_BTC 数量 0.4/0.1，WRISKDEMO_USDT 4000/1000；USD 测试估值 24000/6000。任何真实资产模式或报价不应改变 |
| 点击模拟划转，再导入 | BTC 数量变为 0.3/0.2，Spot/Funding 19000/11000，小计仍 30000 |
| 模拟同步失败 | 原快照保留但状态 failed；当前小计、压力、集中度不可用，历史可估值部分及时间单列并标注失效。失败批次不可导入，不理解为资产清零 |
| 使用固定样例测试部分失败/有效零/无快照 | 现有 JSON 恢复入口；部分失败只计算成功部分并标注范围，有效空快照显示零，无快照显示不可用。不要导入这些边界样例至主程序 |
| 模拟缺价格 | BTC 数量仍保留；缺价格明确可见；已估值小计 10000，不允许导入不完整模拟价格 |
| 检测公开网络接口 | 无密钥成功才证明发行版代理可达；失败只记录网络/地区/权限问题，不能改成成功 |
| 重启程序、重新打开插件 | 模拟状态持久化；失败的当前不可用及历史金额/时间也保持。没有承诺关闭程序仍同步 |
| 导出模拟 JSON，再恢复 | 固定样例和风险结果一致；恢复不自动写主程序；测试 JSON 无凭据 |
| 主程序便携备份恢复 | 单独恢复主程序账户，再用插件 JSON 恢复插件状态；不应假设 addon storage 包含在便携备份 |

## 如何记录

在 `docs/VALIDATION.md` 追加日期、Windows/Wealthfolio 版本、ZIP SHA256、上述每项通过/失败、必要的脱敏错误。不要记录个人资产、真实密钥或含敏感数据的截图。成功后把 CURRENT 的唯一任务改为下一项。

卸载插件会清除插件状态，但不会自动删除 WRISK 主程序账户和资产。清理仅在独立测试资料库手动完成；不要删除真实账户。
