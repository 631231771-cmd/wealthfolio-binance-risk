## 2. 未完成（阻断“完全日常使用”）

1. **后台自动同步未实现**：所有定时器仍在插件 React 页面内；切到原生仪表盘后不会继续。当前只有手动同步，或在插件页可见时更新。SDK/宿主是否支持页面之外运行未验证，因此不提供“绿色后台灯”。
2. **myTrades 自动成本仍是原型**：FIFO 重建、手续费、超卖、余额对账已有合成测试，但没有分页查询、预算、界面与真实授权流程。本轮没有读取任何真实成交。
3. **正式 Profile 隔离未在真实客户端验证**：没有创建/切换真实 Profile，无法确认插件 storage、secrets、后台生命周期是否按 Profile 隔离。
4. **真实宿主写入未执行**：账户创建、快照、报价模式切换、报价写入只在虚构宿主验证。
5. **历史估值/绩效**：HOLDINGS 快照每日一个点，TWR/IRR/波动率/回撤无数据，保持 N/A；没有补造历史。

## 3. 根因与宿主限制

| 现象 | 根因 | 插件能做什么 |
|---|---|---|
| 9 项资产 Yahoo 同步失败 | 资产为 MARKET 且无 provider，`effective_provider` 默认 Yahoo；Crypto 也走该默认 | 写入后切 MANUAL，停止自动同步；不关闭全局 Yahoo |
| 成本 500 被当成市价 | MANUAL 资产快照会用 `average_cost` 生成 12:00 备用报价 | 用同一 quote id 写市场价覆盖；失败明确为部分完成 |
| USDT 汇率“不可用” | 日期汇率接口只接受 3 位代码 | 回退 `getAll()` 最新汇率；保留诊断 |
| 现金基础货币换算 | 快照的 `sum_cash_in_currency` 走日期接口，USDT 被拒后按未换算金额计入 | 无法修复；预览提示宿主按 1:1 计入现金的风险 |
| 原生报价无 TTL | 宿主没有报价过期判断 | 每次同步推送市场价；不同步就不更新 |
| 报价全局生效 | `quotes.update` 按资产写入 | 预览提示共享资产影响；MANUAL 资产跳过第三方提供者 |

## 5. 结论

**可进入“正式账户迁移预验收”，但不是“可长期无人值守使用”。**

允许的预验收范围：新 Profile → 连接只读账户 → 录入并确认成本 → 预览 → 首次写入 → 原生页核对 → 手动重复同步。
阻断项：后台自动同步、myTrades 自动成本、真实 Profile 隔离验证。

在这些阻断项解决前，不应把当前版本描述为“日常自动同步的连接器”。
