# v0.2.1 产品精修与数据展示边界

日期：2026-10-19。基线391f85b4，当前开发分支feature/dynamic-spot-quotes。浏览器预览只使用固定虚构数据与内存transport，不调用宿主、真实API或存量凭据。

## 审查结论

旧版总值、持仓行、配置和微额判断分别选择当前/历史数据，过期时出现总值仍在但配置空白、排序与折叠跳变。逐行旧价兜底还容易让新数量与旧市值并排。首页重复状态抢占资产层级，未知收益占用过大，自动余额同步藏在连接设置中。

本轮附件仅有任务文字，未收到文中两张Windows截图。没有观察用户真实持仓页面；通过当前源码和虚构场景复现问题。参考[Wealthfolio官方产品图](https://wealthfolio.app/)的大数字、克制层次、资产行，以及[TradingView配置说明](https://www.tradingview.com/support/solutions/43000756102-overview-portfolio-distribution/)的市值与比例口径；没有复制其图表、资源或收益模型。

## 当前与历史的边界

- DirectSpot在可发布时保存整份估值记录：快照、报告、覆盖、数量和原始采集时间一起深拷贝，只在内存。不改变风险引擎或报价/余额TTL。
- 新余额先独立发布数量；尚无足够报价时不把旧完整记录覆盖成临时USDT小计。取得新报价后允许更新为较新的部分覆盖记录，不能永久偏爱旧完整记录。
- portfolioPresentation只在账户、数据模式、批次、采集起止、资产身份和数量相同的情况下复用整份历史记录。余额失效，或仅剩USDT恒等计价且历史有市场报价时，整页切换为历史展示。
- 历史模式的总值、持仓、排序、微额、配置和详情均来自同一记录。采集时间保持原值，价差批次显示时间范围，不将刷新失败时刻写成成功时刻。
- 新余额与旧记录不匹配时，显示新数量和当前可估值范围。旧总值仅单列为另一份历史记录，不逐行借用旧价/旧市值，不隐藏新缺价资产。
- 部分新报价仍显示当前部分覆盖，USDC缺价不按1补齐。配置分母是显示记录的已估值小计，明确标注；缺价不等于零。
- 风险页始终使用当前报告；历史总值与比例不能进入当前压力损失、集中度或主程序账本。合法空账户仍显示0。

## 视觉与交互

- 顶部只保留账户会话状态、同步余额、刷新行情和连接设置。余额过期不等于认证失败；真实失败仍有独立固定诊断入口。
- 总值是视觉中心，未知累计盈亏缩成小区块，仍不伪造成本、收益率或资产曲线。
- 四列持仓与资产配置按同一估值记录排列；小于0.1 USDT的可靠微额折叠，配置汇总为微额行。未知市值不可折叠，折叠不改变总值/分母。
- 历史状态使用标题、时间和一条提示，不在每一行重复失效声明。数量变化后不把旧微额判定带到新记录。
- 币种使用本地装饰性识别符，未知资产用通用几何符号；不下载图标、不把图案当作身份验证。
- 余额自动同步入口移到首页。必须已有成功连接且本人勾选逐项核对才能开启；默认手动、频率和原setAuto校验不变。公开行情自动节奏、单飞、限流和可见性策略不变。
- 深色低饱和配色、等宽数字、统一按钮；容器查询适应宿主窄面板。详情保留原生dialog/Escape/焦点回退，开发工作台仍从连接设置进入。
