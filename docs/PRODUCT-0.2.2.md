# v0.2.2 数据可信度与界面精修

## 结论与边界

基线 `dd438c6`（0.2.1），本轮在其上修复报价保留、缺价分类、历史快照身份与展示口径，并精修首页。
所有验证使用虚构余额与内存 transport；未读取真实 UID、持仓、凭据或日志，未发送私人请求。

## 报价结果分类（src/public-market.ts）

一次刷新现在产出六个互不替代的计数：

| 字段 | 含义 | 是否驱动退避 |
|---|---|---|
| `pricedCount` | 本轮真正取得的新报价 | 否 |
| `retainedCount` | 没有新报价、但仍在使用 TTL 内既有报价 | 否 |
| `missingQuoteCount` | 已验证市场本次没有返回 ticker（含 -1220 停牌） | 否 |
| `noMarketCount` | exchangeInfo 明确无 USDT 市场，或代码无法构成交易对 | 否 |
| `failedRequestCount` | 网络/HTTP/解析级失败 | 是 |
| `unexaminedCount` | 预算截断，未检查 | 否 |

- **失败不再清空报价**：`publish()` 把新报价合并到旧报价之上，旧价保留原 `asOf`，由 `mergeDynamicPublicSpotPrices` 按 120 秒 TTL 决定是否进入当前估值。失败状态仍记录在 `status` 与 `failedRequestCount`。
- **缺失 ticker 行 ≠ 无市场 ≠ 请求失败**：HTTP 200 少一行只增加 `missingQuoteCount`；`-1121` 才写入无市场缓存（3 分钟）；`-1220`（单 symbol + symbolStatus 不匹配）按暂时缺价处理，不删除已验证市场。
- **页面隐藏只暂停**：`SpotQuoteReader.pause()` 仅递增 epoch 阻断迟到结果，不销毁价格；显式 `disconnect()` 才清空。
- **退避**：只有 `failedRequestCount>0` 才累加失败；首次重试 30 秒，之后 60/120/240 秒，上限 300 秒。429/418 的 Retry-After 冷却不变，迟到响应仍生效。
- **预算不变**：32 请求 / 20 单项回退 / 100 候选，未放宽。

## 历史快照

- `balanceIdentity(state)` = 账户 id + dataMode + 资产身份 + 数量（排序后），**不含** `asOf/batchId/采集起止`。同一份持仓在新时间被重新读取，仍可复用同一份估值记录。
- 数量变化、卖出、新增资产、账户变化 → 身份不同 → 不得复用。
- 同一余额上，完整记录不会被后续部分估值降级；余额变化时才整体替换。
- 历史展示保留记录自己的余额时间、报价时间与记录时间，不宣称当前总值。
- 断开连接保留参考记录，但当前估值与风险返回 null。

## 展示状态（src/portfolio-view.ts）

`valuationState()` 输出六种状态，`heroLabel()` 给出唯一口径：

| 状态 | 标题 | 标签 | 数值含义 |
|---|---|---|---|
| `live` | Spot 资产总值 | 当前有效 | 完整当前估值 |
| `live-partial` | 已定价小计 | 部分覆盖 | 仅已定价范围，非完整总值 |
| `history-complete` | 上次完整估值 | 历史快照 | 历史完整记录 |
| `history-partial` | 上次部分估值 | 历史 · 部分覆盖 | 历史且部分覆盖 |
| `zero` | Spot 资产总值 | 当前有效 | 成功读取的真实零余额 |
| `unavailable` | 暂无可信估值 / Spot 已估值资产 | 等待更新 | 无任何可信金额 |

"此前估值"提示只在金额或覆盖范围确实不同时出现；单纯时间不同不制造第二个数字。

## 界面

- 顶部只保留一行行情状态：`公开行情已更新 · 每分钟` / `公开行情更新失败 · 5 项沿用有效期报价 · 30 秒后重试`，错误时可展开原因。原独立提示条已合并。
- Hero 右栏移除占位盈亏，改为估值覆盖、最大单资产与成本状态；不再用大号破折号占位。
- 持仓：数量 8 位小数（极小显示 `<0.00000001`）、价格 8 位有效数字并千分位、金额两位；详情显示可用/锁定。
- 微额：表头开关替代 `<details>`，展开状态不再因刷新丢失；缺价资产不折叠、不当作零。
- 资产配置保持独立模块：稳定配色（按资产代码哈希）、前 3 项集中度、历史配置时间与当时覆盖。
- 窄屏（420px 容器）表格收紧后四列可见；≤1000px 单列堆叠。

## 已知限制

- 未接入成本，盈亏仍为"—"。
- 只覆盖直接 USDT 市场，无反向/多跳换算。
- 历史参考仅会话内存，不持久化、不导出。
- 报价时效按插件时钟判断，系统时钟大幅回拨会使报价被视为未来而丢弃。
