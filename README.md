# Wealthfolio 币安风险插件：最小可行性验证

本项目只验证「官方 Wealthfolio Windows 桌面版 + 独立 Addon」。不 Fork 主程序，不修改 WorldState，不连接真实交易所账户，不是完整风险管理产品。

当前项目根目录：`F:\Code\风控`。2026-10-13 已完整迁出旧 world 目录，后续开发、文档和验收均在此进行。既有安装包原样保留；包内 README 属于原构建快照，工作路径以本文件为准。

## 当前状态

**v0.1.9：独立小额Spot直接只读连接。** 用户已授权新增精确主机api.binance.com，仍须本人在宿主批准、输入密钥并确认首次请求。每次查询先核对apiRestrictions纯只读/IP限制，再读取account并核对预期UID；只在插件会话内存显示，不写主程序账本。真实数量独立于所有模拟数据；旧本地EXE/JSON为备用路径，不再是主要方式。

已知签名URL可能进入本机宿主错误日志，**未修复宿主漏洞**；首次界面明确本人接受剩余风险。Key/Secret只由本人在本机密码框输入、官方secrets保存；输入时助手暂停桌面观察，不读剪贴板。不要上传日志或把密钥发聊天。实际验收程度见CURRENT/VALIDATION。

默认关闭自动刷新；成功查询并本人对账后可开启5分钟刷新，余额/报价6分钟有效。仅插件页面可见时运行，切页/最小化暂停，返回后到期补查；禁用/重启需重新确认。SDK不能取消已发请求，超时后底层未结束不重试，断开不发新请求、不发布迟到结果。详细本机步骤见[直接连接验收](docs/DIRECT-SPOT.md)。

**v0.1.8历史基线：本地只读读取器＋手动余额快照交接。** 此备用路线保留；独立Windows读取器用DPAPI保管凭据，只实现Spot GET time/account。默认启动为虚构验收模式，真实模式必须另行授权。插件独立导入白名单快照，保留数量/来源/UID/时间与缺价/过期提示，再使用已有公开报价估值；不与旧模拟账户合计、不写宿主或备份。实际测试结果见VALIDATION。

本机宿主已为3.10.0，3.9.1/3.10.0均存在签名URL宿主日志风险并拒绝localhost；本方案不让认证经过宿主，也没有本地监听服务。取舍是余额必须由用户主动交接，读取失败也需导入失败快照，否则旧余额最多到60秒TTL才失效。凭据仅在辅助程序密码框输入，余额JSON仍需按财务隐私保护。完整操作、真实模式前置条件和安全边界见 [本地读取器说明](native/README.md)。v0.1.7官方secrets虚构值生命周期已在本机3.10.0验收；新版撤下其真实凭据输入框，旧代码仅保留离线回归。

点击「刷新真实公开行情」读取五个USDT交易对，以 BTC0.4、ETH2、BNB10、SOL20、DOGE1000、USDT4000 固定模拟数量计算估值；金额随行情变化，不是真实资产或账户余额。独立内存模块不与离线样例相加，不写主程序、普通存储或模拟备份。展示采集时间，ticker没有成交时间；报价120秒失效，每10秒刷新显示，无自动采集。失败/断开时当前不可用，旧报价仅历史参考；429/418冷却，无自动重试。模拟断网按钮只注入失败状态，不改变系统网络。实机/自动化结果以VALIDATION最新节为准。

新增 `multi` 样例：BTC 0.4×50000、ETH 2×2500、BNB 10×500、SOL 20×150、DOGE 1000×0.1，加 USDT 4000，合计 **37100 USDT**。非 USDT 资产回落 20% 损失 **6620 USDT**；这个情景不覆盖 USDT 兑美元脱锚。列表含数量、报价/时间/来源、当前市值、占比及每币情景损失。`multi-missing` 缺 ETH 报价、另有 7 个无市场映射的 NOPAIR，已定价部分 32100 / 损失 5620，完整总额不可用。

离线报价映射来自模拟官方 exchangeInfo 的 baseAsset/quoteAsset、TRADING 与 Spot 标记，不猜后缀；没有明确市场/价格、歧义映射或过期行情时保留数量、显示缺口。未知法律类型不假称股票。离线模块及74项既有测试保留；v0.1.5 Windows独立资料库验收已通过，v0.1.4自身未安装复验。公开模块不会替换离线认证传输。

新增一个 Binance 账号的 Spot 模拟区：固定 GET、时间校准、HMAC、响应验证、十进制余额、独立报价、UID 去重和失败保留快照。先保存固定假凭据 v1，再点击「读取模拟 Spot／重复读取」。normal 为 0.4 BTC + 4000 USDT，BTCUSDT 报价 50000，结果 24000 USDT，BTC -20% 损失 4000 USDT。USDT 是计价单位，不假定与 USD 平价。可选择零余额、缺价、401/403/429、签名、时钟和超时情景。

新 Spot 会话仅在内存，重开页面需重新采集，不保存/导出到旧 fixture-state-v1；不写主程序、不与历史基准相加。Funding 未覆盖，Stocks unsupported，整个 Binance 总资产不可用。余额 TTL 60 秒、报价 120 秒；页面每 10 秒检查时效，没有自动采集。删除假凭据先断开新链路，禁止在途结果发布。

旧 [精简审查材料](docs/REVIEW-PACKET.md) 仅对应 v0.1.4/dbdf2cd，其行号不适用新版本；本轮不调用 Astra，也不重新审计。[Git 接力流程](docs/GIT-WORKFLOW.md) 说明如何继续。独立私有仓库的 main 保留 v0.1.3，Spot 位于 feature/spot-readonly-offline。

保留 v0.1.3：候选安全槽读回后切换、删除/重启检查；严格模拟备份白名单（formatVersion=2，兼容正常 v1）；外部余额采集起止时间及余额/价格/FX 时效；跨钱包汇总阻断；Funding 原始字段不计算总量。v0.1.4 共 65 项自动化测试已通过，桌面状态见 VALIDATION。

认证发送仍硬阻断：官方网络错误可能带签名 URL，宿主通用 invoke 会写日志；插件不能修复上游日志。AI 的首次真实测试配置与局限见 [安全证据](docs/SECURITY.md)。以下已实现宿主功能指旧模拟基线，不代表本版授权了真实路径。

- 固定目标：Wealthfolio **v3.9.1**，该版本仓库中的 SDK / 开发工具版本为 **3.9.0**。
- 已有模拟基线：页面、Spot/Funding 固定快照、风险纯函数、独立持久化/备份；旧版还有主程序账户持仓写入/读回。v0.1.3 撤下宿主访问，仅保留离线回归，不将其称为当前权限。
- 风险函数：已覆盖资产小计、完整总资产可用性、单资产/账户权重、最大权重、HHI、确定性压力情景损失；支持 CNY/USD 固定汇率样例。
- Binance Stocks：**未支持**，无模拟成功的股票持仓。现有订单或成交接口不能证明当前真实持仓。
- Windows 基线：官方 v3.9.1 中 v0.1.1 的专用模拟账户写入、读回、估值、重复导入、划转、异常批次拒绝和重启持久化通过。v0.1.2 修复当前风险可用性，33 项离线测试通过；各版本实际桌面复验状态见 [验证记录](docs/VALIDATION.md)。
- v0.1.3 官方 Windows 假凭据保存、重启读取、替换、删除 null 已通过；真实凭据、原生故障保护、签名日志及 AI 禁止读取验收、Funding 口径、桌面文件备份恢复仍未完成。自动定时同步、完整风险产品和新仓位模拟未实现。
- v0.1.2：全部失效/无快照/全缺价时底层当前小计和压力返回 null，页面显示不可用；成功零余额仍显示 0；部分覆盖只报告有可靠估值范围。保留快照单列金额、时间及历史失效提示，不能作为当前实时资产。零资产的集中度比例不可用。模拟成本为 0，主程序收益栏不具备真实收益含义。
- 现货和资金同步目前是**离线响应模拟**。签名与请求构造已测试，不代表真实账户 API 已连通。

## 给用户的安装与验收

当前插件包位于 `artifacts/wealthfolio-binance-risk-0.1.8.zip`，辅助程序位于 `artifacts/spot-reader/WealthfolioSpotReader.exe`，旧包原样保留。插件权限未扩展，主机仍只有data-api.binance.vision；不能批准api.binance.com或localhost。辅助程序独立使用固定只读请求，默认不联网。各版本实际桌面结果见VALIDATION。

安装官方 [v3.9.1 Windows x64 发行版](https://github.com/wealthfolio/wealthfolio/releases/tag/v3.9.1)，使用独立测试资料库，在插件管理页选择从本地 ZIP 安装并审核权限。逐步操作见 [Windows 验收](docs/WINDOWS-ACCEPTANCE.md)。

不要在真实资产资料库首次尝试。旧版验收创建了 WRISK 模拟账户/WRISKDEMO 资产，卸载插件不会删除它们；v0.1.3 不再读写这些账户。断开和本地删除凭据也不撤销币安密钥，将来必须在币安端撤销不再使用的密钥。

## 技术栈与本地检查

TypeScript + React + 官方 Addon SDK；Vite 构建；Decimal.js 定点计算；noble/hashes 离线 HMAC；Node 内置测试器。没有额外服务、数据库框架、图表框架或真实密钥输入界面。开发工具需 Node 24（本轮使用 24.17.0）；运行 ZIP 不需要 Node。

```powershell
cd F:\Code\风控
npm ci
npm run verify
```

`verify` 依次检查类型、运行测试、构建、打 ZIP、加载编译入口并静态渲染页面。静态渲染和 SDK 替身测试**都不是官方桌面安装测试**。官方开发工具可用 `npm run dev:server`，但调试模式要求上游调试构建；本轮交付走发行版 ZIP 安装，不自行构建上游。
