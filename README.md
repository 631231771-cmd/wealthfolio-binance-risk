# Wealthfolio Binance Spot 资产总览

本项目使用「官方 Wealthfolio Windows 桌面版 + 独立 Addon」。用户已报告成功读取独立小额Binance Spot的9项持仓且数量逐项核对一致；估值、自动刷新和后续稳定性尚未验收，不是完整风险管理产品。

项目根目录为当前仓库。后续开发、文档和验收均在此进行，旧 WorldState 仓库与本项目分离。既有安装包原样保留；包内 README 属于原构建快照。

## 当前状态

**v0.2.0 产品重构：** 总览突出Spot资产价值，持仓为资产/数量/价格/市值四列；点击详情，微额折叠，配置按市值排序，风险独立页签，开发工具从连接设置单独进入。USDC等稳定币通过已验证USDT市场报价，不硬编码平价。

成功连接后公开行情每分钟自动更新；余额默认手动，用户对账后可开启5分钟自动。行情2分钟、余额6分钟时效，失败/过期保留明确历史参考，缺价不算零。成本尚未可靠取得，盈亏显示“—”，本轮未启用成交历史接口。

[产品依据、限制与本人验收](docs/PRODUCT-0.2.0.md)。页脚版本/源码指纹应与本地构建回执一致。`npm run preview:build`可生成纯虚构、无外部网络的独立浏览器预览；它不是宿主安装验收。

以下为历史改动，当前流程以v0.2.0为准。

**v0.1.14首次连接集中修复：** 连接最短路径为同一Spot主机time→只读权限→余额→UID核对→立即显示币种和数量。第一个合格校时样本即继续，最多3次只对可恢复公开失败重试；不放宽时间/权限/身份校验。首次连接不请求行情，连接后可单独点击“更新公开估值”。5分钟自动刷新仍默认关闭、只刷新余额；报价未更新或过期显示缺价，保留现有风险分析和UI。用户随后报告真实Spot读取及9项数量核对通过；估值、自动刷新及稳定性尚未完成。文档不含真实UID或持仓明细。技术判断与验收步骤见[连接复核](docs/CONNECTION-REVIEW-20261016.md)。

以下为历史改动，当前流程以上段为准。

**v0.1.13余额解析整改：** 按官方账户结构保留数值安全UID、SPOT和balances数组校验，取消错误的纯ASCII资产限制，UTF-8身份不规范化、不改前缀，缺价非零数量继续保留。零记录在完整校验后才省略。余额拒绝新增HTTP/JSON状态、校验层级、固定字段路径和原因码，不显示真实UID/币名/余额或原始响应。未知校验异常明确标SNAPSHOT_BUILD_FAILED，不编造根因；只打一个包，等待本人一次查询，未声明真实连接成功。

**v0.1.12定点诊断：** 连接设置内新增无凭据公开time对照，两个已授权主机各最多3次串行请求；只显示安全摘要。校时区分字段异常、墙钟跳变、慢样本和大偏移，保留2秒/60秒限制并取低耗时合格样本。插件计时器、宿主调用拒绝、HTTP响应错误分层；未知宿主字符串只报HOST_REQUEST_FAILED，不猜原因。实际宿主对照状态见CURRENT/VALIDATION，编译不代表实测；仅本人查询时才读存量凭据并发认证。

**v0.1.9：独立小额Spot直接只读连接。** 用户已授权新增精确主机api.binance.com，仍须本人在宿主批准、输入密钥并确认首次请求。每次查询先核对apiRestrictions纯只读/IP限制，再读取account并核对预期UID；只在插件会话内存显示，不写主程序账本。真实数量独立于所有模拟数据；旧本地EXE/JSON为备用路径，不再是主要方式。

已知签名URL可能进入本机宿主错误日志，**未修复宿主漏洞**；首次界面明确本人接受剩余风险。Key/Secret只由本人在本机密码框输入、官方secrets保存；输入时助手暂停桌面观察，不读剪贴板。不要上传日志或把密钥发聊天。实际验收程度见CURRENT/VALIDATION。

默认关闭自动刷新；成功查询并本人对账后可开启5分钟刷新，余额/报价6分钟有效。仅插件页面可见时运行，切页/最小化暂停，返回后到期补查；禁用/重启需重新确认。SDK不能取消已发请求，超时后底层未结束不重试，断开不发新请求、不发布迟到结果。详细本机步骤见[直接连接验收](docs/DIRECT-SPOT.md)。

**v0.1.8历史基线：本地只读读取器＋手动余额快照交接。** 此备用路线保留；独立Windows读取器用DPAPI保管凭据，只实现Spot GET time/account。默认启动为虚构验收模式，真实模式必须另行授权。插件独立导入白名单快照，保留数量/来源/UID/时间与缺价/过期提示，再使用已有公开报价估值；不与旧模拟账户合计、不写宿主或备份。实际测试结果见VALIDATION。

本机宿主已为3.10.0，3.9.1/3.10.0均存在签名URL宿主日志风险并拒绝localhost；本方案不让认证经过宿主，也没有本地监听服务。取舍是余额必须由用户主动交接，读取失败也需导入失败快照，否则旧余额最多到60秒TTL才失效。凭据仅在辅助程序密码框输入，余额JSON仍需按财务隐私保护。完整操作、真实模式前置条件和安全边界见 [本地读取器说明](native/README.md)。v0.1.7官方secrets虚构值生命周期已在本机3.10.0验收；新版撤下其真实凭据输入框，旧代码仅保留离线回归。

新增 `multi` 样例：BTC 0.4×50000、ETH 2×2500、BNB 10×500、SOL 20×150、DOGE 1000×0.1，加 USDT 4000，合计 **37100 USDT**。非 USDT 资产回落 20% 损失 **6620 USDT**；这个情景不覆盖 USDT 兑美元脱锚。列表含数量、报价/时间/来源、当前市值、占比及每币情景损失。`multi-missing` 缺 ETH 报价、另有 7 个无市场映射的 NOPAIR，已定价部分 32100 / 损失 5620，完整总额不可用。

## 给用户的安装与验收

当前插件包位于 `artifacts/wealthfolio-binance-risk-0.1.8.zip`，辅助程序位于 `artifacts/spot-reader/WealthfolioSpotReader.exe`，旧包原样保留。插件权限未扩展，主机仍只有data-api.binance.vision；不能批准api.binance.com或localhost。辅助程序独立使用固定只读请求，默认不联网。各版本实际桌面结果见VALIDATION。

安装官方 [v3.9.1 Windows x64 发行版](https://github.com/wealthfolio/wealthfolio/releases/tag/v3.9.1)，使用独立测试资料库，在插件管理页选择从本地 ZIP 安装并审核权限。逐步操作见 [Windows 验收](docs/WINDOWS-ACCEPTANCE.md)。

不要在真实资产资料库首次尝试。旧版验收创建了 WRISK 模拟账户/WRISKDEMO 资产，卸载插件不会删除它们；v0.1.3 不再读写这些账户。断开和本地删除凭据也不撤销币安密钥，将来必须在币安端撤销不再使用的密钥。

## 技术栈与本地检查

TypeScript + React + 官方 Addon SDK；Vite 构建；Decimal.js 定点计算；noble/hashes 离线 HMAC；Node 内置测试器。没有额外服务、数据库框架、图表框架或真实密钥输入界面。开发工具需 Node 24（本轮使用 24.17.0）；运行 ZIP 不需要 Node。

```powershell
# 在项目根目录运行
npm ci
npm run verify
```

`verify` 依次检查类型、运行测试、构建、打 ZIP、加载编译入口并静态渲染页面。静态渲染和 SDK 替身测试**都不是官方桌面安装测试**。官方开发工具可用 `npm run dev:server`，但调试模式要求上游调试构建；本轮交付走发行版 ZIP 安装，不自行构建上游。

## v0.1.10最小诊断修复

保留0.1.9布局，错误正文仅在2MiB字符/UTF8上限内解析数字code，显示固定阶段/安全码、HTTP状态和数字业务码，不显示msg或原始响应。只读检查仍严格，分别说明读取关闭、IP白名单关闭、额外权限或字段不完整。币价保留有效小数，市值仍两位。

## v0.1.11首次查询提示修正

点击确认只代表开始连接，不代表读到资产。首次查询进行中或失败时保留原UID、密码输入及确认控件，只有成功接纳余额快照后才隐藏，不再过早卸载表单。显示“本机存有连接资料，但尚未验证可用”，不把保存标记当成真实有效密钥。

HTTP400/-2008按认证拒绝处理并保留数字码，不再提示为余额响应格式错误。此码在当前币安公开Spot/Wallet错误表未找到；[CCXT币安适配器](https://github.com/ccxt/ccxt/blob/master/ts/src/binance.ts)将它列为AuthenticationError并注释Invalid Api-Key ID，仅参考分类、未复制代码。它不能单独证明本机保存内容、请求传递或平台哪一环出错；不读取现存密钥、不自动替换/创建密钥、不再主动查询。

本人已明确选择独立小额测试账户纯只读、不强制IP白名单，并接受连接资料泄露后资产信息可能被他人读取的风险。此决定仅覆盖旧版ipRestrict必须true：仍须明确布尔值，enableReading必须true，九项危险权限必须false，未知true/缺字段继续拒绝。四项本人确认保留并更新权限风险说明，不扩展请求/权限/账户范围。
